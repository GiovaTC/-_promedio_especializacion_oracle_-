programa en Visual Studio 2026 con C# y Oracle Database 19c para calcular el promedio académico de los 46 estudiantes
de una especialización universitaria y almacenar la información en la base de datos .

La propuesta será una aplicación de consola, sencilla para practicar C#, SQL y conexión a Oracle mediante Oracle.ManagedDataAccess.
1. ¿Qué hará el programa?
- Solicitar los datos de 46 estudiantes.
- Registrar el nombre y la nota final de cada estudiante.
- Validar que las notas estén entre 0.0 y 5.0.
- Calcular el promedio individual y el promedio general de la especialización.
- Guardar los registros en Oracle 19c.
- Consultar e imprimir los resultados en la consola.
Utilizaremos una escala académica de 0.0 a 5.0, habitual en Colombia. Podrás ajustarla si tu universidad emplea otra escala.

Ejecuta el siguiente script desde SQL Developer conectado con tu esquema de trabajo.
sql/crear_tabla.sql
CREATE TABLE ESTUDIANTES_ESPECIALIZACION (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    NOMBRE VARCHAR2(100) NOT NULL,
    NOTA_FINAL NUMBER(3,2) NOT NULL,
    FECHA_REGISTRO DATE DEFAULT SYSDATE NOT NULL,
    CONSTRAINT CK_NOTA_ESPECIALIZACION
        CHECK (NOTA_FINAL BETWEEN 0 AND 5)
);

Esta tabla almacenará cada estudiante y su nota final.

ConexionOracle.cs
Esta clase establece la conexión con Oracle 19c.
using System.Text.Json;
using Oracle.ManagedDataAccess.Client;

namespace PromedioEspecializacionOracle;

public static class ConexionOracle
{
    public static OracleConnection CrearConexion()
    {
        string ruta = Path.Combine(
            AppContext.BaseDirectory,
            "appsettings.json");

        if (!File.Exists(ruta))
        {
            throw new FileNotFoundException(
                "No se encontró el archivo appsettings.json.",
                ruta);
        }

        using JsonDocument documento =
            JsonDocument.Parse(File.ReadAllText(ruta));

        string cadena = documento.RootElement
            .GetProperty("Oracle")
            .GetProperty("ConnectionString")
            .GetString()
            ?? throw new InvalidOperationException(
                "La cadena de conexión no está configurada.");

        return new OracleConnection(cadena);
    }
}

EstudianteDAO.cs
Esta clase inserta los estudiantes, consulta el promedio individual y calcula el promedio general directamente en Oracle.
using Oracle.ManagedDataAccess.Client;

namespace PromedioEspecializacionOracle;

public class EstudianteDAO
{
    public void GuardarEstudiantes(List<Estudiante> estudiantes)
    {
        using OracleConnection conexion =
            ConexionOracle.CrearConexion();

        conexion.Open();

        using OracleTransaction transaccion =
            conexion.BeginTransaction();

        try
        {
            const string sql = @"
                INSERT INTO ESTUDIANTES_ESPECIALIZACION
                    (NOMBRE, NOTA_FINAL)
                VALUES
                    (:nombre, :nota)";

            foreach (Estudiante estudiante in estudiantes)
            {
                using OracleCommand comando =
                    new OracleCommand(sql, conexion);

                comando.Transaction = transaccion;

                comando.Parameters.Add(
                    "nombre",
                    OracleDbType.Varchar2,
                    100).Value = estudiante.Nombre;

                comando.Parameters.Add(
                    "nota",
                    OracleDbType.Decimal).Value =
                    estudiante.NotaFinal;

                comando.ExecuteNonQuery();
            }

            transaccion.Commit();

            Console.WriteLine(
                "\nLos registros fueron guardados correctamente.");
        }
        catch
        {
            transaccion.Rollback();
            throw;
        }
    }

    public decimal ConsultarPromedioGeneral()
    {
        using OracleConnection conexion =
            ConexionOracle.CrearConexion();

        conexion.Open();

        const string sql = @"
            SELECT AVG(NOTA_FINAL)
            FROM ESTUDIANTES_ESPECIALIZACION";

        using OracleCommand comando =
            new OracleCommand(sql, conexion);

        object? resultado = comando.ExecuteScalar();

        if (resultado == null || resultado == DBNull.Value)
            return 0m;

        return Convert.ToDecimal(resultado);
    }

    public void ConsultarEstudiantes()
    {
        using OracleConnection conexion =
            ConexionOracle.CrearConexion();

        conexion.Open();

        const string sql = @"
            SELECT ID, NOMBRE, NOTA_FINAL, FECHA_REGISTRO
            FROM ESTUDIANTES_ESPECIALIZACION
            ORDER BY ID DESC
            FETCH FIRST 46 ROWS ONLY";

        using OracleCommand comando =
            new OracleCommand(sql, conexion);

        using OracleDataReader lector =
            comando.ExecuteReader();

        Console.WriteLine("\nESTUDIANTES REGISTRADOS");
        Console.WriteLine(
            "--------------------------------------------------------------");
        Console.WriteLine(
            "{0,-6} {1,-28} {2,-12} {3}",
            "ID", "NOMBRE", "NOTA", "FECHA");
        Console.WriteLine(
            "--------------------------------------------------------------");

        while (lector.Read())
        {
            Console.WriteLine(
                "{0,-6} {1,-28} {2,-12:F2} {3}",
                lector.GetInt32(0),
                lector.GetString(1),
                lector.GetDecimal(2),
                lector.GetDateTime(3).ToString("dd/MM/yyyy"));
        }
    }
}

Importante: la consulta de los últimos 46 registros es adecuada para una ejecución de práctica. En un sistema utilizado por varios grupos o periodos académicos, conviene añadir un identificador de grupo o periodo para calcular el promedio exclusivamente de la especialización correspondiente .

Program.cs
Este es el programa principal. Solicita 46 nombres y notas, valida los datos y presenta los resultados.
namespace PromedioEspecializacionOracle;

internal class Program
{
    private const int CANTIDAD_ESTUDIANTES = 46;
    private const decimal NOTA_MINIMA = 0m;
    private const decimal NOTA_MAXIMA = 5m;

    static void Main()
    {
        Console.Title = "Promedio de Especialización - Oracle 19c";

        Console.WriteLine("==============================================");
        Console.WriteLine(" PROMEDIO DE ESPECIALIZACIÓN UNIVERSITARIA");
        Console.WriteLine("              ORACLE DATABASE 19c");
        Console.WriteLine("==============================================");

        List<Estudiante> estudiantes = new();

        try
        {
            Console.WriteLine(
                "\nIngrese los datos de los 46 estudiantes.\n");

            for (int i = 1; i <= CANTIDAD_ESTUDIANTES; i++)
            {
                Console.WriteLine($"\nEstudiante {i} de {CANTIDAD_ESTUDIANTES}");

                string nombre;

                do
                {
                    Console.Write("Nombre completo: ");
                    nombre = Console.ReadLine()?.Trim() ?? "";

                    if (string.IsNullOrWhiteSpace(nombre))
                    {
                        Console.WriteLine(
                            "El nombre no puede estar vacío.");
                    }
                    else if (nombre.Length > 100)
                    {
                        Console.WriteLine(
                            "El nombre no puede superar 100 caracteres.");
                        nombre = "";
                    }

                } while (string.IsNullOrWhiteSpace(nombre));

                decimal nota;

                while (true)
                {
                    Console.Write("Nota final (0.0 a 5.0): ");

                    string entrada = Console.ReadLine() ?? "";

                    // Admite tanto coma como punto decimal.
                    entrada = entrada.Replace(',', '.');

                    if (decimal.TryParse(
                        entrada,
                        System.Globalization.NumberStyles.AllowDecimalPoint,
                        System.Globalization.CultureInfo.InvariantCulture,
                        out nota)
                        && nota >= NOTA_MINIMA
                        && nota <= NOTA_MAXIMA)
                    {
                        break;
                    }

                    Console.WriteLine(
                        "Nota inválida. Ingrese un valor entre 0.0 y 5.0.");
                }

                estudiantes.Add(new Estudiante
                {
                    Nombre = nombre,
                    NotaFinal = nota
                });
            }

            Console.WriteLine("\n==============================================");
            Console.WriteLine(" RESUMEN DE CALIFICACIONES");
            Console.WriteLine("==============================================");

            decimal suma = 0m;

            foreach (Estudiante estudiante in estudiantes)
            {
                Console.WriteLine(
                    $"{estudiante.Nombre,-30} " +
                    $"Nota: {estudiante.NotaFinal:F2}");

                suma += estudiante.NotaFinal;
            }

            decimal promedioLocal =
                suma / estudiantes.Count;

            Console.WriteLine("\nCantidad de estudiantes: " +
                              estudiantes.Count);

            Console.WriteLine("Suma de las notas: " +
                              suma.ToString("F2"));

            Console.WriteLine("Promedio calculado en C#: " +
                              promedioLocal.ToString("F2"));

            // Guardar los 46 estudiantes en Oracle.
            EstudianteDAO dao = new EstudianteDAO();

            dao.GuardarEstudiantes(estudiantes);

            // Consultar el promedio directamente en Oracle.
            decimal promedioOracle =
                dao.ConsultarPromedioGeneral();

            Console.WriteLine("\n==============================================");
            Console.WriteLine(" RESULTADO PROCESADO EN ORACLE 19c");
            Console.WriteLine("==============================================");

            Console.WriteLine(
                $"Promedio general en Oracle: {promedioOracle:F2}");

            Console.WriteLine(
                $"Total de estudiantes procesados: {estudiantes.Count}");

            dao.ConsultarEstudiantes();
        }
        catch (Exception ex)
        {
            Console.WriteLine("\nERROR EN LA APLICACIÓN");
            Console.WriteLine(ex.Message);
            Console.WriteLine(
                "Verifique la conexión, los permisos y la tabla Oracle.");
        }

        Console.WriteLine("\nPresione una tecla para finalizar...");
        Console.ReadKey();
    }
}

SELECT COUNT(*) AS TOTAL_ESTUDIANTES
FROM ESTUDIANTES_ESPECIALIZACION;

SELECT
    ROUND(AVG(NOTA_FINAL), 2) AS PROMEDIO_GENERAL,
    MIN(NOTA_FINAL) AS NOTA_MINIMA,
    MAX(NOTA_FINAL) AS NOTA_MAXIMA
FROM ESTUDIANTES_ESPECIALIZACION;

Nota importante: el código de ejemplo conserva los registros de ejecuciones anteriores. Para obtener el promedio exclusivamente de los 46 estudiantes de una ejecución nueva, utiliza una tabla vacía al comenzar las pruebas o identifica cada grupo mediante un periodo o lote de procesamiento. No elimines datos existentes en una base compartida sin verificar primero su contenido.
